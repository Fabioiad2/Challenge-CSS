# Paesaggi d'Italia

Piccola esercitazione di sviluppo web front-end: un sito statico dedicato a tre città italiane, realizzato con HTML e CSS. Ogni pagina presenta una città, la relativa regione e collegamenti alle altre località.

## Pagine

- `index.html` — Milano, Lombardia (pagina principale)
- `roma.html` — Roma, Lazio
- `napoli.html` — Napoli, Campania

Le immagini delle città si trovano in `static/img/`; il foglio di stile condiviso è `style.css`.

## Avvio in locale

Non sono necessarie dipendenze o installazioni. Clona o scarica il repository e apri `index.html` nel browser. Per provarlo con un server locale, dalla cartella del progetto esegui:

```bash
python -m http.server 8000
```

Poi visita [http://localhost:8000](http://localhost:8000).

## Tecnologie

- HTML5
- CSS3

## Note

Il sito è un esercizio didattico e non richiede build né backend. Il campo autore è attualmente un segnaposto.
